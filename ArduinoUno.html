Что понимает редактор кода
Пишите код в стиле Arduino — большинство синтаксиса C++ работает как есть.
  • void setup() / void loop()
  • pinMode(pin, OUTPUT|INPUT|INPUT_PULLUP)
  • digitalWrite(pin, HIGH|LOW), digitalRead(pin)
  • analogWrite(pin, 0–255) — ШИМ (реально на 3,5,6,9,10,11)
  • analogRead(A0) или analogRead("A0") — 0–1023
  • delay(ms), millis()
  • Serial.begin/print/println — вывод в монитор порта
  • Типы int / float / long / bool / String — как в C++

Поддерживается сабсет C++. Шаблоны, указатели, классы и препроцессор — не работают.
